# Math Quiz (Python)

Command-line speed quiz: answer as many random arithmetic questions as you can in 60 seconds.

## Done so far

- Random questions using +, -, * and / (division questions always use a divisor, so answers are whole numbers)
- 60-second timer, running count of correct answers
- Single file: `main.py`

## Run

```bash
python main.py
```

## Future scope

- Difficulty levels and a custom time limit
- Score history and a leaderboard
- Replace `eval` with explicit arithmetic
- Simple web or GUI version
